Some signals look guilty: `pg-pool.connect` spans that take a second, a connection pool with dozens of waiting requests, a `pg` upgrade deployed yesterday.

Check them against each other:

- `pg_stat_statements` (`./lab psql`, or the table at the bottom of the dashboard) says the queries take a few milliseconds on average.
- 10 connections × a few ms per query is thousands of queries per second; the API sends about a hundred.

So the database is fast, yet *everything* inside the API is late at the same moments: queries, pool callbacks, even the `/metrics` scrapes. In a Node.js process, what has to be free for any callback to run? Look at the **Node.js runtime** row, and compare `p99` with `max`.
