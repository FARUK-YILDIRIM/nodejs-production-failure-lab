Start from what customers feel, then follow the time.

On the dashboard, compare **Latency at the edge** with **Latency measured by the API**. The edge (Traefik) says p95 ≈ 2 s. What does the API itself say for the same routes?

If the two disagree, the missing time is spent *somewhere between* the proxy and the code that measures it. Open a slow `GET /api/products/:id` trace in Jaeger: when does the API's first span start, compared to the proxy's?
