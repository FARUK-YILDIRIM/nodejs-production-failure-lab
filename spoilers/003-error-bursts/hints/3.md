Since Node.js 15, an unhandled promise rejection terminates the process. Look for a promise that is started and then neither awaited nor given a `.catch()`. The `void` operator is a common way to tell linters "I know", without actually handling anything.

Then check how often that call fails. MailWave's delivery log (`http://localhost:8025/v1/messages?orderId=<id>`) shows each attempt and its status, and Jaeger shows the calls from the API to `mailwave`. A provider that answers 99.4 % of requests correctly is a healthy provider. The question is what the API does with the other 0.6 %.
