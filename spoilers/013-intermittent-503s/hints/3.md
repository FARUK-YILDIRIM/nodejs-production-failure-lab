Since 2.26.0, `/ready` fails as soon as any dependency is unhealthy. TaxRate's health endpoint reports "degraded" during its database failovers, so every instance fails readiness at the same moment, and the proxy, left with no instance, answers 503 to every request, even those that never touch TaxRate.

Readiness should only say whether this instance can serve requests at all. Problems with a shared dependency belong to the requests that use it, which fail or degrade on their own. Keep the dependency report if it's useful, but somewhere the proxy doesn't read.
