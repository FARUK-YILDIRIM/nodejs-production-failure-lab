Since v7, about one product in ten has no precomputed vector, and Recommendations computes it on the fly: 8 to 20 seconds of one of its 8 workers. A few such requests per second keep every worker busy, and all the other requests, which would take 20 ms, wait in the queue behind them. The API waits up to 30 s for an answer, longer than any shopper, then fails the page.

"Customers also bought" is a nice-to-have. Give the call a timeout that fits the page's budget, make sure the timeout cancels the request itself (an `AbortSignal`, not a `Promise.race`), so Recommendations stops working on requests nobody waits for. And when it doesn't answer in time, show the page without its suggestions. The query the page used before 2.24.0 is still in the code.
