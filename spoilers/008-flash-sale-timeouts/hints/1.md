A card authorization takes a few hundred milliseconds, yet checkouts take seconds. Where does the rest go? Open a slow `POST /api/orders` in Jaeger (*Min Duration*: `2s`) and find the span that takes the time.

Then look at what the database's sessions are doing while it's slow. In `./lab psql`:

```sql
SELECT pid, state, wait_event_type, wait_event,
       now() - xact_start AS in_transaction_for,
       pg_blocking_pids(pid) AS blocked_by,
       left(query, 80) AS last_query
  FROM pg_stat_activity
 WHERE datname = 'shop' AND backend_type = 'client backend'
 ORDER BY xact_start;
```

Run it a few times: the picture changes every second, but its shape doesn't.
